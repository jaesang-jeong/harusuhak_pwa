## 📌 프로젝트 소개
**하루수학**은 초·중·고등 및 실생활 수학을 아우르는 **한국 2015/2022 개정 수학과 교육과정 성취기준**에 맞춰 매일 날짜에 맞춰 한 문제씩 학습할 수 있는 모바일 웹/PWA 애플리케이션입니다.

- **결정론적 일일 출제 엔진**: 같은 날짜에는 모든 사용자에게 동일한 '오늘의 공식 문제'가 출제됩니다.
- **파라메트릭 문제은행 (`SeededRNG`)**: 버튼 하나로 숫자, 조건, 4지선다 보기, 단계별 풀이가 동적으로 새로 생성되어 같은 유형을 무제한으로 연습할 수 있습니다.
- **2주(14일) 자동 순환 스케줄러**: 수준별로 14개 핵심 성취기준이 주차별/요일별로 교대 출제됩니다.
- **오개념 기반 매력적 오답 생성**: 부호 실수, 역수 혼동, 단위 착오 등 실제 학생들이 자주 하는 실수를 계산하여 보기를 구성합니다.
- **100% 로컬 프라이버시 & 오프라인 캐시**: 서버 없이 브라우저(LocalStorage)에 학습 기록 및 오답노트가 저장되며, Service Worker로 오프라인에서도 작동합니다.

## 🚀 빠른 시작

### 1. 로컬 웹 서버 실행
```bash
# npm 사용 시
npm start

# 또는 Python 간이 서버
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`으로 접속합니다.

### 2. 문제은행 무결성 검증 테스트
```bash
npm test
# 또는
node test-bank.js
```
총 56개 유형 × 25회 무작위 변형 = 1,400개 문항에 대해 4지선다 중복 없음, 정답 범위, 3단계 풀이 해설, 시드 일관성을 자동 검증합니다.
