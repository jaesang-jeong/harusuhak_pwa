하루수학 (HaruSuhak) - 한국 교육과정 파라메트릭 문제은행 PWA & 모바일 앱

1. 주요 기능 요약
- 매일 날짜에 맞춰 한 문제 표시 (결정론적 날짜 시드 기반으로 같은 날에는 동일한 공식 문제 제공)
- 문제은행 형식으로 숫자·조건 등의 변수를 동적 변형하여 문제 출제 ('🔄 숫자 바꿔 변형 문제 풀기' 무제한 지원)
- 한국 실제 수학과 교육과정(2015·2022 개정 교육과정 성취기준 코드) 및 교과서·학력평가 대표 유형 반영 (총 56개 유형)
  * 기초 수학 (초등 4~6학년 14개 유형):

    - [5수01-05] 분수의 덧셈과 뺄셈 (이분모 분수 덧셈)
    - [6수04-03] 비와 비율 (백분율 계산)
    - [5수03-06] 다각형의 둘레와 넓이 (사다리꼴 넓이)
    - [6수04-05] 비례식과 비례배분 (구슬 배분)
    - [5수05-01] 평균과 가능성 (평균 역산 시험 점수)
    - [6수01-08] 분수의 나눗셈 (역수 곱셈 원리)
    - [6수01-11] 소수의 나눗셈 (몫과 남는 양 소수점 위치)

    - [6수03-08] 직육면체의 부피와 겉넓이
    - [5수03-05] 다각형의 넓이 (마름모 넓이)
    - [5수02-02] 규칙과 대응 (성냥개비 대응 관계식)
    - [6수05-02] 원그래프와 띠그래프 (항목별 수량과 중심각)
  * 중등 수학 (중학교 1~3학년 14개 유형):
    - [9수02-04] 문자와 식 (괄호가 있는 일차방정식)
    - [9수01-01] 수와 연산 (소인수분해와 약수의 개수)
    - [9수02-05] 일차방정식의 활용 (거리·속력·시간 왕복)
    - [9수02-15] 일차함수와 그래프 (기울기와 절편)
    - [9수02-09] 미지수가 2개인 연립일차방정식
    - [9수03-11] 피타고라스 정리 (빗변과 직각삼각형 변의 길이)
    - [9수02-22] 이차함수와 그래프 (표준형 꼭짓점과 축)
    - [9수01-07] 정수와 유리수의 혼합계산 (거듭제곱과 사칙연산)

    - [12경수-02-02] 부가가치세(VAT 10%) 공급가액 분리 역산
    - [12실수-01-04] 스마트폰 고속 충전 전력(W)과 소비 전력
    - [12실수-02-03] 체질량지수(BMI) 계산과 비만도 판정
    - [12경수-03-01] 피셔 방정식 (명목금리와 물가상승률, 실질 수익률)

- 실시간 키워드 검색: 문제은행 탭에서 성취기준, 단원명, 핵심 키워드로 즉시 검색
- 객관식 4지선다 답안 확인, 개념 힌트, 3단계 상세 풀이(STEP 1~3) 및 학생 오개념 기반 매력적 오답 자동 구성
- 주간 요일별(월~일) 스탬프 진행률, 연속 학습 기록(Streak), 오답 노트 및 변형 문제 복습 기능
- 기기 브라우저(LocalStorage)에 학습 기록 저장 및 JSON 백업 내보내기
- PWA 홈 화면 설치 및 오프라인 캐시(Service Worker) 지원 + 향후 Capacitor 네이티브 모바일 앱 빌드 대응

2. 개발 과정에서 웹브라우저 테스트 방법
- 상단 헤더 우측의 [🧪 테스트] 버튼을 클릭하면 '웹브라우저 개발·테스트 시뮬레이터'가 열립니다.
  * 날짜 이동 시뮬레이터: [◀ 어제(-1일)], [오늘], [내일(+1일) ▶] 및 날짜 선택기를 통해 매일 날짜가 바뀔 때 출제되는 문제와 연속 학습 기록을 즉시 테스트할 수 있습니다.
  * 변수 변형 테스트: [🎲 숫자/변수 즉시 변형 출제] 버튼으로 현재 문제의 시드와 생성 변수 목록, 정답 인덱스를 실시간 인스펙터로 확인할 수 있습니다.
  * 모바일 기기 프레임 뷰: [📱 모바일 기기 프레임 토글]을 누르면 데스크톱 브라우저 화면에서 스마트폰 베젤 크기로 모바일 앱 레이아웃을 점검할 수 있습니다.

3. 로컬 실행 및 검증 명령어
- 문제은행 수학적 무결성 테스트 (56개 유형 1400회 변형): node test-bank.js (또는 npm test)
- 로컬 웹 서버 실행: npx serve . -l 8080 (또는 python -m http.server 8080) 후 http://localhost:8080 접속
